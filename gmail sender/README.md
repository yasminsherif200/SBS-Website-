<h1>📧 Gmail Bulk Automation App</h1>

<p>
A simple Node.js + React tool for sending bulk emails (text + images) to multiple Gmail users using a Gmail App Password.
</p>

<hr>

<h2>📁 .env Setup</h2>

<p>Create a <code>.env</code> file in the project root:</p>

<pre>
EMAIL_ADDRESS=your@gmail.com
EMAIL_APP_PASSWORD=your_app_password
PORT=3000
</pre>



<hr>

<h2>⚙️ Install & Run</h2>

<h3>Backend</h3>
<pre>
cd server
npm install
node index.js
</pre>


<hr>

<h2>✅ Usage</h2>
<ul>
  <li>Write the email subject</li>
  <li>Write the message (supports HTML)</li>
  <li>Upload images (optional)</li>
  <li>Upload CSV of Gmail addresses (optional)</li>
  <li>Click "Send"</li>
</ul>

<hr>

<p>That's it — fast setup, easy bulk sending.</p>
